# 0001：按 Cell Mask 生成局部计算域

- 状态：已接受
- 日期：2026-07-15

## 背景

全域 DEM 约有 4,311 万个 30 m Cell，不适合生成或传输全域 GeoJSON，也不应为一次局部洪水推演构建全域 ANUGA mesh。旧实现只支持固定 75×56 窗口，其 Cell 身份、固定 mesh 和输出尺寸无法扩展到全域任意位置。

## 决策

用户可以绘制一个矩形或无孔简单多边形。系统以 Cell 中心点是否落入多边形来生成 Cell Mask，排除 DEM NoData，并要求结果四邻域连通且不超过 25,000 Cell。

Cell ID 使用全域 DEM 行列号。Area Hash 由数据集版本、DEM 网格定义、规范化 Cell Mask 和 mesh 规则共同生成。

锁定区域时生成并缓存 Local Mesh。每个 Cell 沿固定的西南—东北对角线拆成两个三角形；所有局部外边界使用透射边界。区域改变时不得裁剪已有入口，必须经用户确认后清空入口。

建筑源覆盖范围之外按“无建筑”处理：`building_fraction=0`、密度等级为 0，并使用各场景的基础曼宁值（low 0.03、middle 0.04、high 0.05）。

## 后果

- 同一 Cell Mask 可以复用 mesh 与栅格映射，即使用户绘制多边形的顶点顺序不同。
- Scenario 和 Job 必须引用不可变 Simulation Area，而不能继续只引用固定模型版本。
- 输出窗口和 mask 随区域变化，但仍对齐全域 DEM transform。
- 全域建筑覆盖率和三套曼宁栅格成为允许任意区域运行 Job 的前置数据。
- 首版不支持孔洞、不连续区域或多个多边形。
